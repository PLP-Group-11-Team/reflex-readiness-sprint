# Reflex Readiness Sprint

Group 11 prototype for the PLP Reflex Readiness Sprint.

Reflex is a lightweight delivery-management prototype for small Kenyan retailers.

## Core workflow

Retailer creates delivery → Dispatcher assigns rider → Rider picks up → In Transit → Customer confirmation → Delivered

## Repository structure

- `backend/` — Django + Django REST Framework API
- `frontend/` — role-based user interface
- `docs/` — architecture and shared API contract

The prototype architecture and API contract are frozen before implementation so Backend, Frontend and Integration work against the same rules.
